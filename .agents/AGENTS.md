# Правила работы с проектом

## 1. Стек технологий
- Фреймворк: **React 19** + **TypeScript**
- Сборщик: **Vite**
- Стилизация: **Tailwind CSS v4** (используется `@tailwindcss/vite`).
- База данных / Бэкенд: **Supabase** (`@supabase/supabase-js`).
- Иконки: `lucide-react`.
- Анимации: `framer-motion`.

## 2. Менеджер пакетов
- **Использовать ТОЛЬКО `npm`**. В проекте присутствует `package-lock.json`. Запрещено использовать `yarn`, `pnpm` или `bun`, чтобы не нарушить дерево зависимостей.

## 3. Линтинг и форматирование
- В проекте используется **oxlint** (не ESLint). Для проверки кода использовать команду `npm run lint`.

## 4. Архитектура и структура папок
- `src/components/` — переиспользуемые UI компоненты.
- `src/screens/` — основные экраны/страницы приложения.
- `src/hooks/` — пользовательские React хуки.
- `src/contexts/` — React контексты для управления состоянием.
- `src/lib/` — настройки и клиенты сторонних библиотек (например, клиент Supabase).
- `src/i18n/` — файлы локализации/переводов.
- `src/utils/` — вспомогательные функции.
- `src/types/` — общие TypeScript интерфейсы и типы.

## 5. Миграции базы данных
- В корне проекта находится скрипт `migrate.mjs`, отвечающий за миграции БД. При необходимости изменений в БД, учитывать этот механизм.
